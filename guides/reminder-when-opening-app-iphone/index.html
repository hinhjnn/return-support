How to Show a Custom Message When You Open an iPhone App

By Return’s maker · Reviewed 9 November 2026

You can show your own message when an iPhone app opens by combining App → Is Opened with Show Notification in Shortcuts. It triggers when you open or switch to the app. This is an opening-triggered message; it does not hold the app behind a gate.

Set up the message in Shortcuts

  1. Open Shortcuts and select Automation. Add a personal automation. Apple’s iOS 26 guide describes Create Personal Automation, or the add button if automations already exist.
  2. Choose the App trigger. Select the app, choose Is Opened, and continue. This also covers switching back to that app.
  3. Add Show Notification. Find that action in the action search and add it to the automation.
  4. Enter your message. Replace the action’s text with a short sentence, such as “Reply to Maya, then get back to dinner.”
  5. Choose automatic running and save. Apple’s guide describes turning off Ask Before Running and confirming. If your version offers Run Immediately instead, choose that option. Its position in the setup can vary.
  6. Check it on your phone. Leave the selected app, reopen it, then try switching away and back. Check both the wording and the moment the message appears.

Documentation-based instructions using Apple’s iOS 26 guide, reviewed 9 November 2026. This setup has not been physically tested for this guide; interface labels can vary by iOS version.

Apple documents creating a personal automation, the App trigger, and running without confirmation.

What should happen

Show Notification creates a system notification containing your sentence. It does not ask for a response or pause the shortcut. Because Is Opened triggers on opening or switching, the app may already be on screen when you see the message. Apple’s notification-action explanation.

A Shortcuts notification uses the system’s Shortcuts presentation. The Return example below is a different product, with its own notification and before-app experience.

When Show Alert is the better action

If you want an alert that waits for a response within the shortcut, use Show Alert instead. It can show custom text and pauses the shortcut until the person responds; its Cancel option stops the shortcut. Apple’s Show Alert guide.

Pausing a shortcut does not establish that another app is blocked from opening. Choose it for the interaction it provides, without treating it as a Screen Time restriction.

If the message does not appear

  • Confirm the selected app and Is Opened trigger, rather than Is Closed.
  • Check that the automation is enabled and that your chosen running mode does not require a separate confirmation.
  • Run the notification action in the editor to check the message separately from its trigger.
  • Review Focus and notification presentation if the action runs but you miss its banner. iOS controls how notifications are presented.
  • If it appears again when you return to the app, remember that switching to the app can trigger it too.

For different messages, create separate automations for the apps that need them. Keep the messages relevant enough that seeing them repeatedly remains useful.

A few messages you could adapt

  • Messaging: “I’m here to reply to Maya. After that, I can leave.”
  • A break: “I can take a break. I’d like to choose how long it lasts.”
  • Bedtime: “I wanted to read a chapter tonight. Do I still want that?”
  • Posting: “I opened this to post the photo. What would make this visit complete?”

These are illustrative examples. Use details that mean something to you. If a message feels bossy or vague, edit it or remove it from an app where it does not help.

If you do not need automatic delivery, a note in Notes or on paper is enough to hold your sentence. You will need to revisit it yourself. For the habit behind repeated openings, see stopping unplanned Instagram openings.
