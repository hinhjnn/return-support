Privacy

Privacy Policy.

Return is designed so your Echoes and selected-app settings stay on your device.

Effective 27 August 2026

Information stored on your device

Return stores the Echoes you write, your delivery settings, and the timing and state needed to provide Return’s features. Return also stores opaque app selections supplied by Apple’s Family Controls. This information is stored locally by Return and in local storage shared only among Return’s own app extensions.

Information Return does not collect

Return does not require an account. Return does not include advertising or third-party analytics. Return does not operate a server that receives your Echoes, selected-app choices, or app-use data. Return does not transmit or log the text of your Echoes or raw Family Controls token data.

Apple system services

If you grant permission, Return uses Apple features such as Screen Time and Family Controls, Device Activity, notifications, and Live Activities. Apple controls those system services under Apple’s terms and privacy practices. Return receives only the access Apple makes available through those system APIs.

Support correspondence

If you email return.app.support@gmail.com, you choose what information to send. Google processes that email under its Privacy Policy. Return does not sell information you send for support. Please do not include private Echo text or other sensitive information unless it is necessary for support. You can ask us to delete support correspondence by emailing the same address.

This website

This static site is hosted by GitHub Pages. When you visit it, GitHub may process technical information such as your IP address, browser information, and request logs under the GitHub General Privacy Statement. Return does not add analytics, cookies, forms, or tracking scripts to this site.

Deleting information

You can delete Echoes and change Return settings in the app. Removing Return asks iOS to remove its installed app data. Apple controls deletion timing and any copies in device or cloud backups.

Changes to this policy

If Return’s data practices change, this page will be updated before the revised practice is represented here. The effective date above identifies the current version.

Contact

For privacy questions, email return.app.support@gmail.com.
