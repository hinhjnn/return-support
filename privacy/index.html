Privacy

Privacy Policy.

Return keeps safety-sensitive settings on your iPhone and lets you choose whether to sync your Echoes through your private iCloud database.

Effective 3 September 2026

Information stored on your device

Return stores the Echoes you write, your delivery settings, and the timing and state needed to provide Return’s features. Return also stores opaque app selections supplied by Apple’s Family Controls. This information is stored locally by Return and in local storage shared only among Return’s own app extensions.

Optional iCloud Sync

iCloud Sync is off by default. If you turn it on, Return stores your Echoes and a limited set of supported delivery preferences in Return’s private CloudKit database for your Apple Account so they can stay up to date across devices signed in to the same Apple Account. Echo text and supported preference values are stored in encrypted CloudKit fields. Apple operates iCloud and CloudKit under Apple’s terms and privacy practices.

Your preferred name, protected-app selections, delivery mode on/off choices, Screen Time permission, notification and Live Activity permissions, and active app sessions stay on that iPhone and are not synced. Return pauses iCloud Sync if your Apple Account changes and asks you before merging that iPhone’s data into the new account.

Information Return does not collect

Return does not require a Return account. Return does not include advertising or third-party analytics. Return does not operate a server that receives your Echoes, selected-app choices, or app-use data. If you enable iCloud Sync, Return communicates directly with Apple’s CloudKit service. Return does not transmit or log the text of your Echoes, raw Family Controls token data, or raw Apple user identifiers in its diagnostics.

Apple system services

If you grant permission, Return uses Apple features such as Screen Time and Family Controls, Device Activity, notifications, and Live Activities. Apple controls those system services under Apple’s terms and privacy practices. Return receives only the access Apple makes available through those system APIs.

Support correspondence

If you email return.app.support@gmail.com, you choose what information to send. Google processes that email under its Privacy Policy. Return does not sell information you send for support. Please do not include private Echo text or other sensitive information unless it is necessary for support. You can ask us to delete support correspondence by emailing the same address.

This website

This static site is hosted by GitHub Pages. When you visit it, GitHub may process technical information such as your IP address, browser information, and request logs under the GitHub General Privacy Statement. Return does not add analytics, cookies, forms, or tracking scripts to this site.

Deleting information

You can delete individual Echoes and change Return settings in the app. When iCloud Sync is on, Echo deletions sync to the same private CloudKit database. Turning iCloud Sync off stops future syncing but does not currently provide a separate “Delete Cloud Data” action. Removing Return asks iOS to remove its installed app data, but may not remove records already stored in your private CloudKit database. Apple controls deletion timing and any copies in device or cloud backups.

Changes to this policy

If Return’s data practices change, this page will be updated before the revised practice is represented here. The effective date above identifies the current version.

Contact

For privacy questions, email return.app.support@gmail.com.
