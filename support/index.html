If Return is not behaving as expected, email us and include enough detail to reproduce the issue.

Please remove private information from screenshots before sending them.

What to include

  • Your iPhone model and iOS version.

  • The steps immediately before the issue.
  • A screenshot with private information removed, if it helps explain the issue.

Common questions

Why does Return ask for Screen Time access?

Return uses Apple’s Family Controls features for the Before apps and While using moments on apps you select. You control that permission in iOS.

Can Return read content inside other apps?

No. Apple gives Return opaque selections for the apps you choose; Return does not receive passwords, messages, or content from inside those apps.

How do I remove an Echo?

Open Echoes in Return and use the delete control for the Echo you want to remove.
